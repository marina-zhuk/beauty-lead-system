# Portfolio Case: Beauty Lead System

## Короткое описание

Beauty Lead System — коммерческий MVP для beauty-бизнеса: лендинг, форма заявки, Telegram-уведомление владельцу и сохранение обращения в Google Sheets.

Проект можно показывать как готовый пример услуги для салонов, студий и частных мастеров, которым нужно быстро принимать заявки с сайта и не терять контакты в переписках.

## Для кого

- частные beauty-мастера;
- небольшие салоны красоты;
- студии с несколькими направлениями услуг;
- администраторы, которые вручную обрабатывают обращения из чатов и соцсетей.

## Бизнес-проблема

Заявки приходят из разных каналов: сайт, реклама, Direct, Telegram, WhatsApp, личные сообщения. Без простой системы владелец может поздно увидеть обращение, потерять контакт или забыть вернуться к клиенту.

## Решение

Один понятный поток:

```text
Лендинг -> форма заявки -> API -> Telegram владельцу -> Google Sheets
```

Клиент оставляет имя, телефон, услугу, желаемую дату/время и комментарий. Владелец сразу получает Telegram-сообщение, а заявка сохраняется в таблице для дальнейшей обработки.

## Что входит в MVP

- адаптивный landing page;
- форма заявки с валидацией;
- API endpoint `POST /api/lead`;
- Telegram notification;
- Google Sheets sync через Google Apps Script;
- success/error состояния формы;
- rate limit на отправку заявок;
- документация по setup, API, интеграциям и тестированию.

## Коммерческая ценность

- меньше потерянных заявок;
- быстрее первый ответ клиенту;
- контакты и услуги фиксируются в одном месте;
- владельцу проще контролировать поток обращений;
- систему можно быстро адаптировать под другой beauty-сегмент или локальный бизнес.
